매일 아침 브리핑은 **제미나이 스파크**가 이 캘린더를 읽어 해 줍니다.

- 화면: https://j333333766-hub.github.io/iljeong-kok/ (GitHub Pages, `docs/index.html`)
- 서버: Google Apps Script 웹 앱 (`gas/Code.js`, 시트에 묶인 스크립트)
- 시트: 「일정콕 - 업무일정」 (내 드라이브)
- 캘린더: ‘업무일정(일정콕)’ — 화면 오른쪽 위 📅 단추로 바로 열림. 공유 주소: https://calendar.google.com/calendar/u/0?cid=ZjI2NmU3ODk3OGM2MDEwMzczNTdmZTU4NWMxMGZiY2U4NGY3MDY2NmNjM2YzZWM5NTZlMmU3YzBlMDM5ZWMyNUBncm91cC5jYWxlbmRhci5nb29nbGUuY29t (휴대폰 앱에서 안 보이면 설정에서 이 캘린더를 켤 것)

## 처음 한 번 설정

1. 시트 「일정콕 - 업무일정」을 열고 **확장 프로그램 → Apps Script**.
2. 편집기 위 함수 목록에서 **setup** 을 고르고 ▶ 실행 → 권한 허용(시트·캘린더).
   - ‘일정’ 시트 머리줄, 캘린더 ‘업무일정(일정콕)’, 접속 키가 만들어집니다.
3. 함수 **linkInfo** 실행 → 실행 로그에 나온 **연결 링크**를 휴대폰과 PC에서 한 번씩 엽니다.
   - 링크에 접속 키가 들어 있으니 남에게 보내지 마세요. 한 번 열면 그 기기에 저장됩니다.
   - 직접 넣으려면 화면 오른쪽 위 ⚙ → 웹 앱 주소 + 접속 키(스크립트 속성 `KEY`).

## 쓰는 법

- **등록**: 제목 → 분류(수업·회의·마감·행사·출장·기타) → 날짜(오늘·내일·모레·다음 주 월 단추) → 시간(자주 쓰는 시각 단추, 또는 종일) → 등록하기.
  끝 시각을 비우면 1시간, 시작 시각도 비우면 종일 일정이 됩니다. 여러 날이면 끝나는 날을 넣습니다.
- **목록**: 오늘 / 이번 주 / 다가오는 / 지난. 체크하면 완료(캘린더 제목 앞에 ✅). 누르면 고치기·지우기.
- **마감**: ‘마감’ 분류는 D-day가 붙고 캘린더에서 빨간색으로 보입니다.
- **오늘 브리핑**: 화면 왼쪽 아래. [복사]로 메신저에 붙여 넣을 수 있습니다.
- **시트를 직접 고쳤다면**: 시트 메뉴 **일정콕 → 캘린더와 다시 맞추기**.
  (캘린더에서 직접 고친 내용은 시트로 돌아오지 않습니다. 일정은 앱이나 시트에서 고치세요.)

## 제미나이 스파크 아침 브리핑

제미나이 앱의 스파크(예약 작업)에 아래 지시를 넣고 **매일 오전 7시 30분(평일)** 으로 예약합니다.

```
매일 아침 나의 업무 일정을 브리핑해 줘.
1. 구글 캘린더 '업무일정(일정콕)'에서 오늘 일정을 시간 순서로 정리해 줘. (시작~끝 시각, 제목, 장소)
   제목 앞의 [분류]는 그대로 두고, 앞에 ✅가 붙은 것은 이미 끝난 일이라 빼 줘.
2. 앞으로 7일 안에 있는 [마감] 일정을 D-day와 함께 알려 줘.
3. 오늘 일정 사이에 비는 시간이 30분 이상이면 '빈 시간'으로 알려 줘.
4. 내일 첫 일정도 한 줄로 덧붙여 줘.
짧게, 휴대폰 화면 한 장 안에 들어오게 써 줘. 일정이 없으면 "오늘은 등록된 업무 일정이 없습니다."라고만 해 줘.
```

- 캘린더 대신 시트를 읽게 하려면 1번을 "구글 드라이브의 스프레드시트 '일정콕 - 업무일정'의 '일정' 탭에서 날짜가 오늘인 행"으로 바꾸면 됩니다.
- 스파크가 쓸 수 있는 연결 앱(캘린더·드라이브)이 켜져 있어야 합니다.

## 개발 메모

- 코드 고친 뒤: `clasp push` → `clasp redeploy <배포ID> -d "설명"` (같은 웹 앱 주소 유지). 배포 ID는 `clasp deployments`.
- 화면 고친 뒤: `docs/index.html` 커밋·푸시 → GitHub Pages가 자동 배포.
- 보안: 웹 앱은 ‘모든 사용자’ 공개지만, 요청마다 접속 키를 확인합니다. 키를 바꾸려면 스크립트 속성 `KEY`를 지우고 setup()을 다시 실행 → linkInfo()로 새 링크.
- 시트 열: id, 날짜, 끝날짜, 시작, 끝, 종일(Y), 제목, 분류, 장소, 메모, 상태(예정/완료), 캘린더ID, 등록, 수정.
